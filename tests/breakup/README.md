# Breakup tests

The breakup models TAB, ETAB, Pilch–Erdman, Reitz–Diwakar and KH-RT: unit families and Weber-number sweeps end to end. The results are discussed in the documentation, [Breakup](../../docs/vv/breakup.md); this file holds what is needed
to run the tests and find a case.

## Run

```bash
./tests/test.sh breakup                                 # the whole folder (builds build/verif/ first)
./tests/test.sh <name>                                # one test by its CTest name, e.g. tab-e2e
ctest --test-dir build/verif -L breakup --output-on-failure
```

`khrt-e2e` carries two more CTest entries on its run, `khrt-e2e-rt` (the RT shatter) and `khrt-e2e-threads` (several thread counts). The Weber-sweep cases are generated by `../tools/make_pe_case.py`. Further breakup literature notes: [`LITERATURE_TESTS.md`](LITERATURE_TESTS.md).

An end-to-end case can also be run by hand from its folder, after one `./tests/test.sh` build:

```bash
cd tests/breakup/tab-e2e
../../../bin/IGLOO > run_out.txt 2> run_err.txt && python3 -B check.py
```

The CTest name of a case is its folder name; of a unit family, the `test_*` names in the table.
Each folder's `INFO.md` holds the reference, the oracle and its tolerance, and what a deliberately
broken build gives. General instructions (requirements, reading the report, diagnosing a failure,
adding a test) are in [`../README.md`](../README.md).
