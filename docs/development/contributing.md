# Contributing

---

## Build checklist before a PR

1. Build in both modes and confirm `bin/IGLOO` links cleanly:

   ```bash
   # Standalone
   ./install.sh build --master=None --compilers=intel --use-openmp

   # Hydra-submodule (requires $HYDRADIR set)
   ./install.sh build --master=hydra --compilers=intel --use-openmp
   ```

2. Run the full test suite and confirm the gate is green:

   ```bash
   ./tests/test.sh all
   ```

   See [Testing](testing.md) for details. The target is **43/43** (22 e2e + 21 unit,
   `self_test` among the latter). Nothing is registered `WILL_FAIL`, so any red is a
   real regression — including the three `test_*_probes` bug-transcription pins.

## Comment style

Keep inline comments to **one terse line**. No multi-line derivations, no
reformatting of existing comment style. Match the surrounding code's comment
density.

---

## Adding or changing an `input.ini` key

Any change to a key — name, default, type, semantics — requires **two edits**:

1. **Runtime reader** `src/lib/Lib_INI.f90` — the code that actually parses
   the key at runtime.
2. **Doc registry** `src/lib/config/Register_IGLOO.f90` — the doc-only record
   that `DocGen` uses to generate `docs/user/registry.md`.

After editing both, rebuild DocGen and regenerate the registry page:

```bash
./install.sh build --master=None --compilers=intel --use-openmp
bin/DocGen       # writes docs/user/registry.md
```

!!! warning "Never hand-edit `docs/user/registry.md`"
    It is auto-generated by `DocGen`. Hand edits will be overwritten on the next
    `bin/DocGen` run.

## OpenMP rules

The integration hot path runs under `!$OMP PARALLEL DO`. Two rules are mandatory:

**No implicit-SAVE locals in threaded procedures.** Local variables with
initializers (e.g. `integer :: n = 0`) have the `SAVE` attribute in Fortran and
are shared across threads — a data race. Initialize at runtime instead:

```fortran
! Wrong — implicit SAVE races across threads
integer :: attempt = 0

! Correct — runtime initialization, no SAVE
integer :: attempt
attempt = 0
```

**Module-level scratch must be `!$omp threadprivate`.** Any module variable
used as per-call scratch inside the parallel region must be declared threadprivate
or moved into a local. The `myRay` variable in `IGLOO_RayFaceIntersection3D` is an
example that caused non-deterministic md5 gates before this fix.

## Trajectory ordering

`OUTPUT/trajectories-*.dat` record order within a zone is **OMP-nondeterministic**
across runs. When writing verification scripts or checking regression gates, sort
by particle ID and position before comparing — never rely on byte identity:

```bash
tail -n+3 trajectories-A.dat | sort | md5sum
```
