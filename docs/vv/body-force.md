# Body Force — End-to-End Case

Verifies that the production solver correctly integrates the transverse momentum ODE
under a uniform body acceleration with exact linear Stokes drag, by comparing 25
particle trajectories against the closed-form $v(x)$ solution.

---

## Purpose

The test isolates the body-force path (`bodyAccel` in `Lib_RHS.f90`) by setting
`toll = 1\times 10^{-20}` in the Stokes closure, which makes
$C_d = 24/(\mathrm{Re} + \mathrm{toll})$ exact to machine precision for any Re.
With $k_V = 1$ the axial slip is zero and the particle coasts at $u_g$, so
the transverse ODE is exactly linear and independently solvable in closed form.
This pins the body-force assembly, the drag wiring in `Lib_Equations.f90`, and the
integrator — all against a parameter-free analytic oracle — without thermal coupling
introducing any approximation.

---

## Oracle

With $k_V = 1$ the axial velocity equals $u_g$ everywhere, so time maps to
position: $t = x / u_g$.  The Stokes drag with `toll` = $10^{-20}$ makes the
$\mathrm{Re}/(\mathrm{Re} + \mathrm{toll})$ factor unity to machine precision,
giving a component-wise exactly linear drag.  The transverse ODE is:

$$
\frac{dv}{dt} = -\frac{v}{\tau_v} + g_y, \qquad
\tau_v = \frac{\rho_p\,d^2}{18\,\mu}
$$

with $v_0 = 0$ at injection.  The terminal drift velocity is:

$$
v_\infty = g_y\,\tau_v
$$

and the **time-independent** $x \to v$ relation anchored at the first recorded
point $(x_a, v_a)$ of each particle is:

$$
v(x) = v_\infty + (v_a - v_\infty)\,\exp\!\left(-\frac{x - x_a}{L}\right), \qquad
L = u_g\,\tau_v
$$

For the case parameters:
$\tau_v = \rho_p d^2/(18\mu) \approx 1.287 \times 10^{-3}\,\mathrm{s}$,
$v_\infty = g_y\,\tau_v \approx -0.257\,\mathrm{m/s}$,
$L = u_g\,\tau_v \approx 1.287 \times 10^{-2}\,\mathrm{m}$.

---

## Tolerance

The trajectory file uses format F12.6; each $x$ and $v$ value carries a half-ULP
truncation $\delta = 0.5 \times 10^{-6}$.  The residual
$r = v_\mathrm{meas} - v_\mathrm{pred}(x_\mathrm{meas})$ collects four such
truncations via the partial derivatives at the test point and at the anchor:

$$
\mathrm{tol}(x) = \delta\,\bigl(2 + 2\,|v_\mathrm{meas} - v_\infty|/L\bigr) + 10^{-8}
$$

The $10^{-8}$ floor covers the ODE integrator ($\mathrm{rtol} = \mathrm{atol} =
10^{-11}$; non-binding).  The check is restricted to the resolved window
$|v_\mathrm{meas} - v_\infty| > 10^{-3}\,\mathrm{m/s}$; near terminal drift the
F12.6 floor cannot discriminate the exponential tail.

!!! note "Non-vacuous gate"
    At least $N_\mathrm{good} = 20$ particles must pass the windowed check.
