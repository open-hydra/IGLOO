# Stokes Drag — End-to-End Case

Verifies that the production solver correctly integrates the momentum ODE under
pure Stokes drag by comparing 25 particle trajectories against the closed-form
$x(v)$ solution.

---

## Purpose

Stokes drag is the simplest possible drag closure ($C_d = 24/\mathrm{Re}$) and
produces an exactly integrable momentum ODE.  This case pins the core velocity
relaxation path — the ODE assembly in `Lib_RHS.f90`, the time integration via
`Run_ODESolver`, and the trajectory output format — against an independent analytic
oracle.

---

## Setup

| Parameter | Value | Source |
|-----------|-------|--------|
| Gas viscosity | $\mu = 1.8 \times 10^{-5}\,\mathrm{Pa\,s}$ | `make_box_case.py` `GAS['MIL']` |
| Gas axial velocity | $u_g = 10\,\mathrm{m/s}$ | `make_box_case.py` `GAS['U']` |
| Particle density | $\rho_p = 2950\,\mathrm{kg/m^3}$ | `properties.dat` |
| Particle diameter | $d = 1.189 \times 10^{-5}\,\mathrm{m}$ | `bc.txt` $r_p = 5.945 \times 10^{-6}\,\mathrm{m}$ |
| Inlet velocity scaling | $k_v = 0.1$ → $v_0 = 1.0\,\mathrm{m/s}$ | `bc.txt` |
| Thermal coupling | Disabled ($k_T = 1.0$, zero thermal slip) | `input.ini` |
| Body force | None | `input.ini` |

The inlet velocity $v_0 = 0.1\,u_g$ is well below the gas velocity, so each
particle accelerates toward $u_g$ as it crosses the box — a clean exponential
relaxation that is fully captured within the $L = 0.15\,\mathrm{m}$ domain.

---

## Oracle

Under pure Stokes drag with a uniform gas the axial momentum ODE is linear:

$$
\frac{dv}{dt} = \frac{u_g - v}{\tau}, \qquad \tau = \frac{\rho_p d^2}{18\,\mu}
$$

The solution $v(t) = u_g + (v_0 - u_g)\,e^{-t/\tau}$ can be inverted to give the
**time-independent** $x(v)$ relation anchored at the first recorded point
$(x_a, v_a)$ of each particle:

$$
x(v) = x_a - u_g\,\tau\,\ln\!\frac{v - u_g}{v_a - u_g} - \tau\,(v - v_a)
$$

This formulation eliminates time from the comparison, so it is unaffected by the
ODE solver's internal step-size choices.

For the case parameters: $\tau = \rho_p d^2 / (18\mu) \approx 1.287 \times 10^{-3}\,\mathrm{s}$.

---

## Tolerance

The trajectory file uses format F12.6; each $x$ and $v$ value carries a half-ULP
truncation $\delta = 0.5 \times 10^{-6}$.  The residual
$r = x_\mathrm{meas} - x_\mathrm{pred}(v_\mathrm{meas})$ collects four such
truncations via the partial derivatives $|\partial x / \partial v|$ at the
test point and at the anchor:

$$
\mathrm{tol}(v) = \delta\,\bigl(2 + |dx/dv\,(v)| + |dx/dv\,(v_a)|\bigr) + 10^{-8}
$$

The check is restricted to the relaxation window $v \in [v_a,\, 0.95\,u_g]$; near
saturation ($v \to u_g$) the sensitivity $|dx/dv| \to \infty$ and a ULP-level
$v$ error maps to an unbounded $x$ error — not a code defect, so correctly excluded.

!!! note "Non-vacuous gate"
    At least $N_\mathrm{good} = 20$ particles must pass the windowed check.  This
    guards against a trivially passing case in which the relaxation is too short to
    sample the transient at all.
