# End-to-End Test Methodology

The end-to-end cases validate the full production solver path from injection to
exit on a simple uniform-gas box domain.  They live under their model category in
`tests/` (e.g. `standard/drag-stokes`, `standard/temp-relax`, `evaporation/d2law`),
each with an independent Python oracle (`check.py`) that compares the trajectory
output against an analytic closed form.

---

## Box geometry

All box cases share a 3-D Cartesian box generated by `tests/tools/make_box_case.py`.

| Parameter | Value |
|-----------|-------|
| Domain size | $L_x = 0.15\,\mathrm{m}$, $L_y = 0.05\,\mathrm{m}$, $L_z = 0.05\,\mathrm{m}$ |
| Cell count | $60 \times 5 \times 5$ |
| Cell size | $\Delta x = 2.5\,\mathrm{mm}$ |
| Inlet face | $x = 0$, `bcdef = 401` |
| All other faces | `bcdef = 100` (wall) |
| Gas field | Uniform; stored as `solfile.tec` in Tecplot ASCII format |

The gas file is read by IGLOO's allocation module (`src/lib/allocation.f90`) using
header-name matching over a 21-variable standard gas state.  Variable names must
match exactly; ordering is flexible.

Four case families use other geometries: `vie-plait` a box carrying a non-uniform gas
(`tests/tools/make_vie_case.py`), the `swirl-wedge` family a one-cell annular wedge
(`tests/tools/make_wedge_case.py`), the `vortex-cloud` family a one-cell planar square in
solid-body rotation (`tests/tools/make_vortex_case.py`), and `db-2daxi`/`axis-200`/`wedge-fold`
a real MOSE nozzle solution on an axisymmetric wedge (`tests/common/`).

### `make_box_case.py` knobs

```bash
# Create a box case in the current directory
python3 tests/tools/make_box_case.py \
    --kv 0.1   \   # inlet axial velocity = kv * U_g
    --kt 0.5   \   # inlet temperature    = kt * T_g
    --rp 5.945e-6 \ # particle radius [m]
    --alpha 0.0     # inlet cone half-angle [deg]
```

`--kv 1.0` sets the injection velocity exactly equal to the gas velocity, zeroing
axial slip so that drag is a no-op.  `--kt 1.0` zeroes thermal slip.  These two
knobs are the main isolation switches used to decouple heat and momentum in the
`temp-relax` and `body-force` cases.

## Oracle philosophy

Each `check.py` is an **independent** oracle: it derives the predicted trajectory
purely from the known test inputs (particle properties, gas constants, body-force
settings) without reading any quantity from the production output to define the
reference.  The measured trajectory is used only as the set of $(x, v)$ or $(x, T)$
pairs to test.

### Tolerance derivation

Tolerances are derived from the output format and integrator precision; they are not
tuned to pass.

The trajectory file is written with format F12.6, so every coordinate and velocity
value carries a half-ULP truncation error of $\delta = 0.5 \times 10^{-6}$.  For a
residual $r = q_\mathrm{meas} - q_\mathrm{pred}(x_\mathrm{meas})$ the propagated
tolerance is:

$$
\mathrm{tol}(x) = \delta \cdot \bigl(2 + \text{sensitivity terms}\bigr) + \varepsilon_\mathrm{int}
$$

where the sensitivity terms collect $|\partial r / \partial q_i|$ evaluated at the
anchor and test points, and $\varepsilon_\mathrm{int} = 10^{-8}$ is a floor for the
integrator's own error (with `rtol = atol = 1e-11` the SDIRK4 error is roughly three
orders below the F12.6 floor, so this term is non-binding).

A particle is "verifiable" only when its residual is evaluated in the
**resolved-transient window** — the region away from saturation where the
finite-precision format can still distinguish the prediction from the limit.  Each
case requires at least $N_\mathrm{good} = 20$ verifiable particles to prevent a
vacuous pass when the transient is under-sampled.

### Gate strength

Every gate is falsifiable: it fails on a deliberately broken build — a wrong constant, a
reverted rotation, a fold applied to position only — so a green result is evidence of
something.  Where a case carries a competing model
(VLE against LK, CEM against TC), the discrimination margin between the two is itself
gated so the comparison cannot pass vacuously.

## Run harness

```bash
./tests/test.sh e2e            # run every registered e2e case
./tests/test.sh drag-stokes    # or a single case by ctest name
```

The e2e cases are registered in `tests/CMakeLists.txt` (`igloo_e2e_case`) and run
by CTest under `-DBUILD_VERIFICATION=ON`.  Each case runs the freshly built
`bin/IGLOO` in its own directory with `OMP_NUM_THREADS=5`, `KMP_STACKSIZE=100M`,
and `ulimit -s unlimited`, then invokes its oracle.  The pass criterion is
`check.py` exit 0; the solver's own exit code is not gated (benign compiler stderr
warnings are ignored).  Oracles read the per-parcel files by column: trajectory and
exit rows carry no time unless a case sets `out-time = on`, which appends the particle
time as the last column, and a case that must stop at a fixed time sets `time-end`,
which also writes each particle's state at that time to `snapshot-<mat>.dat`.

!!! info "How the case summaries are grouped"
    The sections below are ordered by **what kind of verification each case is** —
    by what its reference is, and therefore by what a green gate does and does not
    license.  The four groups use the same terms as the taxonomy on the
    [V&V overview](index.md), which also carries the full figure-to-category
    inventory.  Each case appears once, under the kind its figure *uniquely* pins:
    a case whose oracle is a closed form but whose only unshared content is a
    feature path (`periodic-y`, `coupled-body`, `vie-plait`, `swirl-wedge`,
    `swirl-wedge-deposit`, `swirl-wedge-spin`) is filed under base
    features, with its oracle strength stated in place.

## Tier V — closed-form solution verification

The strongest gate kind in the suite.  The reference is the **exact analytic
solution of the model's own governing equation**, evaluated from the case inputs
alone — no digitized figure, nothing read back from the run.  A case is
constructed so that the equation *has* a closed form (zero slip to freeze
$\mathrm{Re}$, a $100\times$ particle $c_p$ to freeze $B_T$, injection at the
terminal velocity to freeze $\mathrm{Nu}$), and the tolerance is a derived
budget (output truncation + integrator floor), never a tuned number.

**Proves:** the full production path — INI parse, injection, RHS assembly,
SDIRK4, cell tracking, output — integrates *that* equation with *those*
constants, to the output floor.

**Cannot prove:** that the equation is the right physics.  A closed-form gate is
blind to a wrong-but-self-consistent model; it also only covers the reduced
regime the closed form exists in (`d2law-line`'s frozen $B_T$, `conv-nu`'s
constant $\mathrm{Re}$), not the general coupled case.

### drag-stokes

Verifies the velocity-relaxation ODE under pure Stokes drag.  See
[Stokes drag](drag-stokes.md).

### temp-relax

Verifies the heat-relaxation ODE in the conduction limit ($\mathrm{Nu}=2$,
$\mathrm{Re}=0$).  See [Temperature relaxation](temp-relax.md).

### temp-relax-varcp

Verifies the enthalpy state of a material whose $c_p$ varies, on a table that starts above 1 K:
`temp-relax`'s box and gas with $c_p = 1000 + (T - 250)$ J/(kg K) tabulated on 250–800 K.  The
state is $h$, $\mathrm{d}h/\mathrm{d}t = K\,(T_g - T)$ with $K = 6\,\mathrm{Nu}\,k_g/(\rho_p d^2)$,
and the temperature is recovered through the table (linear between the nodes, the first and last
segments extended).  On a segment of slope $s$ the temperature relaxes exponentially over the length
$u_g s/K$, and the closed form marches the segments from each parcel's first row.  Four groups of
inlet cells enter at 210 K (below the table), 300 K, 750 K and 840 K (above it).

| Witness | Requirement |
|---------|-------------|
| Every row with $\lvert T - T_g\rvert > 1$ K, every exit | the closed form, within the F12.6 truncation carried through the march |
| `source.tec` | $\sum E = \sum \dot m\,[h(T_0) - h(T_\mathrm{exit})]$ to $10^{-6}$ of the gross exchange |
| Non-vacuity | every parcel of every group verified |

**Result:** 25/25 parcels, the worst row at 0.013 of its tolerance, the energy to $6\cdot10^{-9}$ of
the gross.  A temperature left at its injection value while the enthalpy evolves fails every row
(worst 237 K off); an inversion that reads before the table's first row puts the 210 K group up to
1.87 K off.

### temp-relax-varrho

Verifies that a parcel whose density varies with temperature keeps its mass and that its diameter follows
the density: `temp-relax-varcp`'s case with $\rho = 2950 - 0.5\,(T - 250)$ kg/m³.  With no mass exchange
$d(T) = (6m/(\pi\rho(T)))^{1/3}$, and the heat flux $\mathrm{Nu}\,k_g\,\pi\,d(T)\,(T_g - T)$ follows it; the
reference $T(x)$ inverts $t(T) = \int s\,m/(\mathrm{Nu}\,k_g\,\pi\,d(T)\,(T_g - T))\,\mathrm{d}T$ by Gauss-Legendre
quadrature on each table segment.  The printed diameter is compared with $d(T)$ on every row, to print
precision.  The breakup counterparts `tab-varrho`, `tab-evap-frozen-varrho` and `khrt-varrho` (the
`tab-e2e`, `tab-evap-frozen` and `khrt-e2e` cases with $\rho = 1000 - 0.8\,(T - 270)$ and drops injected at
270 K) require the mass to stay constant between breakup events and the stream mass to be conserved across
them: no mass to the gas, and the exit mass-flow total.

**Result:** 25/25 parcels, the printed diameter within print precision of $d(T)$; the TAB masses constant
between events, $\lvert\dot w\rvert$ 2.2e-18 of the injected flow, the KHRT exit mass flow within 6e-7.  A model-1
parcel printing its injection diameter fails every heated row; a mass resynced at a stale density drifts by
12.75 % (TAB, model 1) or moves the stream mass at every event ($\lvert\dot w\rvert$ 1.2e-9 of the flow; exit
mass flow +3.68e-4).

### body-force

Verifies the transverse body-force acceleration with exact linear Stokes drag
(`toll = 1e-20`).  See [Body-force drift](body-force.md).

### conv-nu

Verifies Ranz–Marshall heat transfer at a constant, non-zero Reynolds number.
The particle is injected exactly at its body-force terminal velocity so that the
transverse slip — and hence $\mathrm{Re}$ and $\mathrm{Nu}$ — is constant along
the whole trajectory.

| Quantity | Value |
|----------|-------|
| Slip Reynolds number | $\mathrm{Re} = 0.204$ |
| Ranz–Marshall Nu | $\mathrm{Nu} = 2 + 0.6\,\mathrm{Re}^{1/2}\,\mathrm{Pr}^{1/3} = 2.240$ |
| Thermal relaxation length | $L = u_g \tau_T = 14.9\,\mathrm{mm}$ |
| Discrimination vs Nu = 2 | $\tau_T$ is 10.7% shorter; well above tolerance |

**Result:** 25/25 particles verified.

This case discriminates the Nu correlation wiring: if the convective term were
dropped and $\mathrm{Nu} = 2$ were used, the predicted $T(x)$ exponent would be
11% too slow — thousands of times the tolerance.

### no-exchange

Verifies the `drag = NoDrag` ($C_d = 0$) and `heat = NoHeat` ($\mathrm{Nu} = 0$) switches.
The inlet injects with **both** slips — $1\,\mathrm{m/s}$ against the gas's $10\,\mathrm{m/s}$
and $300\,\mathrm{K}$ against $600\,\mathrm{K}$ — so any drag or Nusselt law would move the
parcel within the first cells.  With both switched off the parcel equations are
$\mathrm{d}\mathbf{v}/\mathrm{d}t = 0$, $\mathrm{d}T_p/\mathrm{d}t = 0$, and the state is
**exactly** the injection state: $0\times$ finite $= 0$, so no integrator stage moves it.

| Witness | Requirement |
|---------|-------------|
| Every trajectory row and exit | $(u, v, w, T)$ = $(1, 0, 0, 300)$ to the last F12.6 digit |
| `source.tec`, every cell | `wdot`, `Fx`, `Fy`, `Fz`, `E` exactly $0.0$ (exchange from the full-precision state) |
| Non-vacuity | $\ge 20$ parcels, $\ge 60$ rows each, exit at $x = 0.15$ |

**Result:** 25/25 parcels, 1500/1500 cells exactly zero in all five source fields.  A binary
without the two tokens refuses the case at setup (exit 128); each switch alone fails the
oracle on the quantity it leaves on (Stokes drag: $u \to 9.999961$; Ranz–Marshall:
$T \to 600$).

### vortex-cloud

ICE's verification case I run by IGLOO, number for number: a cloud released at the local gas
velocity into a frozen solid-body vortex $u_g = i\Omega z$ ($z = x + iy$, $\Omega = 1$), the
only case where the gas rotates in the plane of the motion — every cross term of the drag
equation between $x$ and $y$ is exercised — and the only one that sweeps the Stokes number
(`vortex-cloud-st0p01`, `-st0p1`, `-st1`, `-st10`).  With Stokes drag and a uniform diameter,
$\tau z'' + z' = i\Omega z$, and a parcel seeded at the gas velocity moves as $z(t) = C(t)\,z_0$
with $C = A e^{\lambda_+ t} + B e^{\lambda_- t}$, $\lambda_\pm = (-1 \pm \sqrt{1 + 4i\Omega\tau})/(2\tau)$:
one complex factor for the whole cloud, whose argument lags $\Omega t$ and whose modulus grows.
The 1672 parcels (an $h/2$ lattice within $4\sigma$ of ICE's Gaussian) stop at a quarter turn,
$t = \pi/2$ (`time-end`), and every row carries its time (`out-time`), so the oracle compares
each row with $C(t)\,z_0$ at the row's own time.

| Witness | Requirement |
|---------|-------------|
| Every time-stamped row and `snapshot-A.dat` record | $\lvert z - C(t) z_0\rvert \le 3\cdot10^{-6}$ m, $\lvert v - C'(t) z_0\rvert \le 3\cdot10^{-6}$ m/s |
| Premise | 1672 parcels from their seed states; all in the snapshot at $t = \pi/2$; no exit; planar single-layer path |
| Oracle self-check | $C(0) = 1$, $C'(0) = i\Omega$, rotation and dilation monotone, RK4 agreement to $10^{-12}$ |

**Result:** at every St the worst residual is the F12.6 print floor, $7.0\cdot10^{-7}$ m and
$7.1\cdot10^{-7}$ m/s, and the cloud's $\lvert C\rvert$ and lag at the quarter turn equal the closed
form to all printed digits (1.015723 / 0.000310 at St 0.01 … 1.828830 / 0.538470 at St 10).
Deliberately wrong inputs miss by $1.4\cdot10^{-3}$ to $1.6$ m: no drag, $\tau$ doubled, seeded at
rest, first-order gas sampling.  The same case solved by ICE and by IGLOO side by side, against
the exact solution at each solver's own time, is the three-way comparison in hydra's
`test/vortex-cloud/` ([open-hydra/hydra](https://github.com/open-hydra/hydra)), which the optional
ctest entry `vortex-cloud-3way` runs where hydra and an ICE binary are present.

### d2law-line

The Tier-V companion to `d2law`: instead of integrating the kernel along
the measured $T_p$, this case realizes the textbook **analytic special case** and
gates against a line built from the case inputs alone.  Production's `d2law` has no
boiling clamp, so $B_T$ normally drifts; here the particle $c_p$ is raised 100×
(a knob that does not enter $K$ at all) so the droplet heats only 0.76 K over the
full residence while $d^2$ still loses 39 %.  With $B_T$ frozen at its injection
value, $d^2(x) = d_0^2 - K_0(x-x_a)/u_g$ with
$K_0 = 8k_g\ln(1+B_{T0})/(c_{p,g}\rho_p)$ — Godsave/Spalding, zero run-conditioning.
The tolerance is a theory budget (monotone $K$-drift bound from the measured $T_p$
span + E13.6 truncation + integrator floor).

**Result:** 25/25; worst residual $3\cdot10^{-4}$ of $d_0^2$ against a
$7\cdot10^{-4}$ budget.  A factor-two error in the evaporation rate would overshoot
the budget by $\sim$250×.

### tab-e2e

The TAB validation case: a 25-drop **radius-based** Weber sweep across the
O'Rourke–Amsden onset $We_r=6$, gated (Tier V) against the paper's damped-oscillator
closed form — the no-break onset and the first-breakup time $t_{bu}$ (1.7–17.5 ms

**Result:** the analytic $t_{bu}$ lands inside every measured bracket to

### etab-e2e

The ETAB validation case: a 25-drop **radius-based** Weber sweep across the
onset $We_r=6$ and the bag$\to$stripping transition $We_\mathrm{trans}=80$.  ETAB
reuses the TAB damped oscillator — so onset and first-breakup time are the same ORA87
closed form gated in `tab-e2e` — and replaces TAB's stochastic Rosin–Rammler product
sizing with a **deterministic exponential cascade** (Tanner eq. 6/8):
$d_\mathrm{child}/d_\mathrm{parent} = \exp(-(K_\mathrm{br}/\omega)\,\arccos(1-1/We_\mathrm{Cr}))$,
with $K_\mathrm{br}/\omega = k_1(A_{We}We^4{+}1)$ on the bag branch and $k_2\sqrt{We}$
on the stripping branch ($\omega$ cancels).  The reference is evaluated at the We *at
breakup*, since the drop decelerates and the bag ratio is steeply We-dependent.

**Result:** 20/20 breaks; child-size ratio within **0.03 %** across both branches;
timing sub-percent.

### solid-box

Solidification (model 6): molten droplets injected at 2400 K into the 600 K box gas at
the gas velocity ($\mathrm{Re}=0$, $\mathrm{Nu}=2$) cool as a liquid, supercool to
$T_n = 0.8\,T_m$, recalesce to $T_m = 2327$ K with the frozen fraction
$f_0 = c_l(T_m - T_n)/h_\mathrm{fus}$, hold a plateau at $T_m$ until $f = 1$, and cool as
solids.  Every regime is a closed form of the inputs in $x = u_g t$; the gates check the
liquid and solid relaxations, the plateau rows and the first plateau row after the
nucleation point, the global energy balance of the source field and the heat deposited in
every plateau cell, $\dot n_p\,\pi d k_g \mathrm{Nu}(T_m - T_g)\,\Delta x/u_g$.  Its
Eulerian twin `solid-box-euler` checks the equivalent-Eulerian field cell by cell.

**Result:** 25/25 parcels in all three regimes; energy balance and plateau heat within the
$\dot m$ print floor (3e-7).

### solid-melt

Melting (model 6): solid particles injected at 1500 K, below $T_n$, into the box gas at
3000 K at the gas velocity ($\mathrm{Re}=0$, $\mathrm{Nu}=2$) heat as solids to $T_m$,
melt there on the plateau at the latent-heat rate
$m\,h_\mathrm{fus}\,df/dt = -\pi d k_g \mathrm{Nu}(T_g - T_m)$ until $f = 0$, and heat as
liquids.  Every regime is a closed form of the inputs in $x = u_g t$; the gates check the
solid and liquid relaxations, the plateau rows between the melt and liquid points, the
exit temperature against the closed form within the chord bound of the interpolated melt
event, the global energy balance of the source field, the heat taken from the gas in every
plateau cell, and that no parcel is lost or stalled at a phase boundary.

**Result:** 25/25 parcels in all three regimes; exit temperature within 1.2e-4 K of the
closed form (2611.7044 K); energy balance and plateau heat within the $\dot m$ print
floor (3e-7).

## Run-conditioned kernel verification

For the coupled evaporation models the mass and energy equations admit no closed
form, so the reference is the model's **rate law integrated along a quantity read
back from the production output** — the measured $T_p(x)$.  The oracle shares no
code with production (independent RK4 / bisection, literature constants), but it
is only *semi*-independent: production supplies the trajectory it is integrated
along.

Each of these cases carries a **silent-regression curve** — the competing model
the case must out-distance (VLE for `lk-neq`, CEM-Spalding for `tc-box`) — and
the discrimination margin is itself gated, so the comparison cannot pass
vacuously.

**Proves:** the mass-transfer *rate law* — Spalding chain, Knudsen depression,
Stefan–Fuchs film term, variable-density swelling — is coded and wired
correctly, and is distinguishable from the neighbouring model.

**Cannot prove:** the temperature evolution.  If the droplet energy balance were
wrong, the measured $T_p$ would be wrong and the oracle would inherit the same
error.  That axis is covered separately by `temp-relax`/`conv-nu` (heat) and by
the unit families' energy checks.

### tc-hexadecane

The Tonini–Cossali validation case: an **n-hexadecane** drop reproducing
TC2012 Fig. 11 ($R_{d,0}$=10 µm, $T_{d,0}$=300 K, air at 600 K).  It is the suite's
variable-property case — the liquid density falls with temperature, so the
drop *swells* as it heats before the $D^2$-law evaporation — and therefore the only
one exercising the temperature-dependent property tables (`rhoTab`/`cpTab`/`hTab`)
inside the integration.

IGLOO's TC kernel **is** TC2012's *present model* (eq. 16): its small-rate
limit reduces to eq. 16's stated form $\hat m=(\hat P_{vs}-\chi_{v,\infty})/[\tfrac12(\tilde
T_s+1)]$ (not the Stefan–Fuchs eq. 2b, which lacks the $(\tilde T_s-1)$ film term).  The
tight gate integrates the droplet **mass** with that present-model rate along the measured
$T_p$ and reconstructs $d^2 = (6m/\pi\rho_\ell(T_p))^{2/3}$ — coupling evaporation and
thermal swelling exactly as production does — and requires every drop to swell.

The saturation pressure is TC2012's own Table-1 curve, carried by the `Psat` column of the
case's `properties.dat` (piecewise Clausius-Clapeyron through the table's anchors), and the
energy sink is Table 1's latent heat at the boiling point, $L_v=2.2695\times10^5$ J/kg: the
curve and the sink are decoupled, which a single scalar $L_v$ cannot do (the curve's effective
latent heat is $\approx$258 kJ/kg over the operating range).  The gate's oracle reads the same
column; two further gates assert that the run reported the tabulation and that its plateau
lies within 1 K of a 0-D replica of the kernel (`zero_d.py`, 492.63 K; with psat by
Clausius-Clapeyron at the same sink it is 486.0 K).  The rate gate alone cannot tell the table
from a Clausius-Clapeyron fit to the same anchors ($7\times10^{-3}$ against a floor of
$1.9\times10^{-3}$, tolerance 2 %); the two plateau gates can.  Liquid
$c_{p,\ell}=2800$ J/(kg K) is the NIST/Chemeo value at ~490 K.  The digitized TC2012 Fig. 11
present-model curves are a non-gating overlay (normalized lifetime, since IGLOO's $D_v$ is
$Le$-set and differs from TC2012's, making absolute $\tau$ incomparable).

**Result:** measured $d^2(x)$ within $0.19\,\%$ of the kernel on all 25 drops, every drop
swells (peak 1.088); plateau 492.6 K against the digitized ~493.7 K ($0.2\,\%$), on its 0-D
replica to the printed digit.

### evap-breakup-box

Evaporation with ODE breakup (model 4).  25 identical 30 µm drops enter a 50 m/s, 600 K gas
at 40 m/s and 300 K ($We_r=30$, $\mathrm{Re}=20$): Reitz–Diwakar stripping shrinks them to
~14 µm in the first 36 mm while the d²-law already removes mass, then evaporation alone
consumes them inside the 0.8 m box.  No published frozen-gas benchmark combines the two
mechanisms, so the oracle composes the two source-verified kernels by the stream-mass rule
(breakup conserves $\dot n_p m$, evaporation removes it):
$\mathrm{d}d/\mathrm{d}t = (d_\mathrm{stable}-d)/	au + 2\dot m_{d^2}/(
ho_l\pi d^2)$ is
RK4-integrated along the measured $u(x)$, $T_p(x)$ over the breakup window, and the d²-law
integral along $T_p(x)$ after it.  The source field must close on the injected flow (every
drop consumed in the box), no cell may take mass from the gas, and all 25 drops must burn out
without a solver-failure exit.  Twins isolate one half each: `d2law-brk-dormant` (the d2law
case under model 4 with a zero breakup rate), `rd-evap-frozen` (the Reitz–Diwakar case under
model 4 with a zero evaporation rate); `test_evap_breakup` pins the right-hand side at one
state and `solver-fail-consumed-m4` the solver-failure exit.

**Result:** composed rate within $1.4\cdot10^{-4}$ of the measured diameter over the breakup
window (tolerance $2\cdot10^{-3}$), the d²-law integral within half its budget after it,
source closure $5\cdot10^{-16}$, 25 burnouts at $x=0.544$ m.

## Tier P — published-model reproduction (validation)

Here the reference is not derived by us at all: it is **something the source
paper itself published**.  Two sub-kinds appear:

- *correlation-gated* — the paper's empirical closed-form expression coded
  directly and evaluated at the measured state.  Pilch–Erdman's $T^*(We)$ table,
  Reitz–Diwakar's fitted $\tau$ and $d_\mathrm{stable}$ ($C=20$ obtained by
  curve-fitting), Reitz-87's KH $\Lambda/\Omega$ correlations.  No digitization
  — but also no analytic solution behind them, which is what separates these
  from Tier V.
- *figure-digitized* — the paper's own plotted result for the paper's own case,
  read off with WebPlotDigitizer and gated as a curve/slope/plateau: `mhb98-water`
  (MHB98 Fig. 2, the M7 model line).

This is the category that catches what the unit tests cannot: a unit oracle
re-coded from the same paper can lockstep a transcription error (a sign in an
exponent), and a direct call cannot tell whether an event path executes at all or
whether an event's result is written back to the ODE state.  The end-to-end
reproduction sees all of that.

**Proves:** under the paper's own conditions IGLOO lands on the paper's own
number — i.e. we reproduce *their model*, not merely our re-coding of it.

**Cannot prove:** agreement with experiment.  Where a case has experimental
points they are drawn as a non-gating overlay only; and a figure on which every
model in the paper coincides (MHB98 Fig. 2) is a weak discriminator no matter
how tightly it is matched.

### pilch-erdman-e2e

A 25-drop Weber sweep
($We\in\{20\ldots1000\}$, one diameter per inlet cell, shared slip $=100$ m/s,
$\sigma=0.072$) against **Pilch–Erdman (1987)'s published total-breakup-time
correlation $T^*(We)$** (Fig. 7, closed form — no digitization).  The gate compares
IGLOO's measured initial breakup rate per drop to the paper's forward rate
$\dot d = (d_\mathrm{stable}-d)/\tau$, $\tau = T^*d/(U\sqrt{\rho_g/\rho_p})$, at the
injection $We$.

The rate gate covers the whole $We\ge45$ sweep — 22 drops, both $T^*$ branches,
tolerance 1 %.  The $18<We\le45$ branch stays with the `test_breakup_pe` unit family:
at fixed slip those drops are too small to resolve a regime crossing in-domain.  The
plateau $d_\mathrm{stable}$ is gated on 5 drops at 12 %.

**Result:** all 22 drops match the paper kernel to $\sim10^{-4}$.

### reitz-diwakar-e2e

A 25-drop radius-based Weber sweep
($We_r$ 8–1000) that gates the RD breakup rate against **Reitz & Diwakar (1987)**, SAE
870598.  RD is model 3 (ODE-path, no event); the shed rate reduces to
$\mathrm{d}d/\mathrm{d}t=(d_\mathrm{stable}-d)/\tau$ with the branch — **bag** or
**stripping** — chosen per drop state.  At slip 100 m/s the $We_r=0.5\sqrt{Re}$ handoff
sits at $We_r=20$, so the sweep exercises both regimes (bag $We_r$ 8–18, stripping
$We_r$ 22–1000).

The stripping constant $C_s=20$ and the bag constant $D=\pi$ are the paper's own
curve-fitted values (SAE 870598), so production is source-faithful to the calibrated form.

**Result:** IGLOO's integrated initial rate matches the RD closed form to $<0.1\,\%$
across all 25 drops (6 bag, 19 stripping); the pointwise formula and the handoff are
independently pinned by the `test_breakup_rd` unit test.

### khrt-e2e

A 25-drop radius-based Weber sweep ($We_r$ 30–1000)
gating the **continuous Kelvin–Helmholtz stripping rate** against Reitz (1987).  The
model-3 shed rate reduces to $\mathrm{d}d/\mathrm{d}t=(d_\mathrm{stable}-d)/\tau_{KH}$
(the same reduction as Pilch–Erdman).  The KH-rate gate is the initial rate at
$We_r\ge340$ — a clean measurement of the continuous ODE, separate from the discrete
events.

The companion `khrt-e2e-rt` gate asserts the Rayleigh–Taylor shatter: eight drops must
collapse discontinuously to the fragment scale ($d/d_0\;0.14$–$0.25$), stay there, and
remain mass-self-consistent — the event's new droplet count is written into the ODE
state and the parcel mass flow re-derived from the event $(d, \dot n)$.  The
$\lambda_{RT}$ child size and $(d/\lambda_{RT})^3$ cubic count (Beale–Reitz Eq. 11)
remain unit-tested.  A third entry, `khrt-e2e-threads`, reruns the case at several OpenMP
thread counts and requires identical output (sorted multisets), since the shed lists are
drained after the parallel region.

`check.py` also closes the gas source on the particle-phase fluxes: $\sum F_x = P_\mathrm{in} -
\sum_\mathrm{exits}\dot m|u_p|$ and $\sum E = E_\mathrm{in} - \sum_\mathrm{exits}\dot m(c_pT +
|u_p|^2/2)$, a KH shed handing its child's birth flux to the child rather than to the gas.
`khrt-shed-noexchange` states the same cell by cell: with `NoDrag` and `NoHeat` a shed is the
only exchange left, and every source cell must be zero.  `khrt-evap-frozen` runs the case with
evaporation on and frozen (model 4): KH rate, RT persistence, children and no mass to the gas.

**Result:** KH stripping within $0.03\,\%$ of the Reitz-87 closed form across the
sweep; RT shatter persists on all eight drops; source budget within the print floor of the
exit flows ($6\cdot10^{-7}$).

### mhb98-water

A paper-reproduction validation case: a single water
droplet reproducing Miller–Harstad–Bellan (1998) Fig. 2 — $D_0=1.1$ mm, $T_{d,0}=282$ K,
$T_G=298$ K, $\mathrm{Re}_d=0$ (quiescent).  IGLOO runs CEM+LK = the uniform-temperature
Langmuir–Knudsen model = MHB98's **M7** (M8 is the finite-conductivity variant, superimposed
on M7 in this figure), so the gate compares the integrated IGLOO trajectory to the
**digitized M7 model curve** (WebPlotDigitizer, both panels).  The CTest gates are (i)
IGLOO-vs-the-LK-kernel (tight, RK4 along the measured $T_p$), (ii) the coupled-physics
identity $K=(T_G-T_\mathrm{wb})\,8k_g/(\rho_\ell L_v)$, and (iii) a **paper-reproduction
gate** on the M7 curve: IGLOO's rate parameter $\beta=(\rho_d\Pr_G/8\mu_G)\,|dD^2/dt|$
(MHB98 Eq. 28) against $\beta_{M7}$ = the least-squares slope of the digitized M7 line
($\approx6.35\times10^{-3}$, itself guarded within ±20 % of the paper's stated
$\beta\approx6\times10^{-3}$, p. 1038), ±10 %; plus IGLOO's wet-bulb against the M7
temperature plateau (282.4 K), ±0.5 K.

Every property in the case is **MHB98's own Appendix-A correlation** (air and water: Harpole
1981), evaluated once at their constant-property reference temperature $T_R=T_{WB}$(Eq. 27)
$=293.968$ K — the paper publishes all of them, so this is the paper's parameterisation, not a
stand-in.  $\mathrm{Le}=1$ and the single-anchor Clausius–Clapeyron $p_\mathrm{sat}$ (their
Eq. 10) are likewise the paper's own settings (Appendix A gives water no $\Gamma_V$/$\mathrm{Sc}$
and states $\mathrm{Le}=1$ as the default in that case).

**Result:** IGLOO **lands on the M7 curve** — $\beta=6.30\times10^{-3}$ vs
$\beta_{M7}=6.35\times10^{-3}$ (**0.8 %**), wet-bulb 282.33 K vs the M7 plateau 282.43 K
(**0.10 K**) — reproducing *their model*, not just our re-coded kernel.
The overlay is plotted **normalized** — $d^2/d_0^2$ vs $t/t_\mathrm{life}$ (with
$t_\mathrm{life}=D_0^2/K$ from the LSQ slope, extrapolated to $D^2\!\to\!0$ rather than taken as
the last sample, at $d^2/d_0^2\approx0.012$).  This sidesteps the paper's own inconsistency (its caption says
$D_0=1.1$ mm $\Rightarrow D_0^2=1.21$, but its plot's M7 line starts at $D_0^2\approx1.10$ and
the axis tops at 1.2); since $\beta$ (Eq. 28) is $D_0$-independent and matches to $<$1 %, the
two normalized $d^2$-law lines **coincide**.  The experimental points are not overlaid: in the
figure the experimental circles sit on M7 ($\approx6.5\times10^{-3}$), and an eyeball
digitization of them is not reliable enough to plot.
Note Fig. 2 is a weak discriminator (all eight models coincide inside 0.47 K, and a direct
pixel measurement of the figure shows IGLOO's 282.33 K lands *on* one of the plotted curves).
The strong one is Fig. 4 decane ($T_G=1000$ K), which spans ~200 K across the same eight
models — gated separately by `test_mhb98_decane`, a **unit** test because that droplet is
suspended at fixed slip; see
[Stefan-blowing reduction $f_2$](literature.md#stefan-blowing-reduction-f_2-mhb98-fig-4-decane).

### mhb98-water-psat

The same droplet with the saturation pressure taken from the `Psat` column that ATLAS GPB writes
for water (its NASA9 $\mathrm{H_2O(L)}/\mathrm{H_2O}$ pair, within 0.1 % of IAPWS at 280–300 K),
the table copied byte for byte: a positive control of the tabulated $p_\mathrm{sat}$ on the
CEM + Langmuir–Knudsen path, and the end-to-end check of the ATLAS-to-IGLOO route.  At 282 K the
table sits 14 % above the case's Clausius–Clapeyron line, so the wet-bulb drops.  Not a
validation: MHB98's M7 line is Clausius–Clapeyron-based, so the M7 legs are not carried; the
gates are the LK kernel with the tabulated $p_\mathrm{sat}$ along the measured $T_p$, the
$K$–wet-bulb identity, the mass balance, the run's report of the tabulation, and the wet-bulb at
least 0.6 K below the Clausius–Clapeyron case.

**Result:** wet-bulb 281.31 K against 282.33 K (−1.02 K); the kernel, the identity and the mass
balance hold as in the parent case.  With the column zeroed the run reproduces the parent's
282.33 K to the printed digit.

## Base features & infrastructure paths

These cases target the **non-physics machinery** every run depends on: gas-field
reconstruction, boundary-condition transport, injection modes, mesh topology, and
the Eulerian feedback accumulators.  Their closures are already gated elsewhere
(`vie-plait`, `swirl-wedge`, `swirl-wedge-deposit` and `swirl-wedge-spin` reuse Stokes drag, `periodic-y` and `coupled-body` reuse the
`body-force` oracle), so what each figure *uniquely* pins is the feature path,
not the physics.

Oracle strength varies inside the category and is stated per case: `vie-plait`,
`periodic-y` and `coupled-body` have full Tier-V closed forms (a folded-modulo
one, in `periodic-y`'s case); `swirl-wedge` has an exact ODE oracle (RK4, self-checked
in-file) gated at the print floor, `swirl-wedge-deposit`
integrates the force on the gas along that oracle and `swirl-wedge-spin` projects its
residence time onto the euler cells; `db-injection` and `db-2daxi` are **behavioral**
— they assert contracts (placement fidelity, hand-off, finiteness, exit through
the intended boundary) with no reference curve at all, because a real MOSE nozzle
field has no analytic solution.  `db-2daxi` is deliberately md5-free: trajectory
bytes drift by 1 ULP across compiler and configure generations.

Several members of this category have **no figure** and so no section below:
`bc-center-2grp` (multi-group `bc_center` pinning), `axis-200` and `wedge-fold` (the
axis face and the sector fold on the MOSE nozzle field), `two-mat` (two materials),
`two-fam-bc` (one inlet table per family in `bc.txt`), `two-fam-bc-2blk` (the same on two blocks joined by
a 101 connection), `varcp-tmin` (a varying-$c_p$ table that ends below the parcels' temperature) and the
`refusals/*` gates —
behavioral cases with no reference curve, summarised in the table on the
[Overview](index.md).  This page is organized around comparison figures;
a case that pins particle *placement* or a *refusal* rather than a trajectory has
nothing to plot.

The routine-level member of this category is the interpolation family
`test_gas_reconstruction` (E1–E5), documented under
[Literature tests](literature.md); `vie-plait` is its in-solver counterpart, the
only case that exercises the 2nd-order gas rebuild inside the integration loop.

**Proves:** the feature is live, self-consistent and does not perturb the
trajectory physics.

**Cannot prove:** anything about the closures themselves — and for the
behavioral cases, nothing quantitative at all.  A behavioral gate passes as long
as the answer is finite and plausible, which is why they are paired with a
closed-form case on the same physics wherever one exists.

### vie-plait

The only e2e case with a **spatially varying** carrier field: the compressive
velocity $v_g = -\epsilon(y-1)$ of Vié et al. (2015, §5.1).  Inertial particles
injected at $U_{p0}=u_{g0}$, $V_{p0}=0$ trace the damped transverse oscillator of
Eq. 5.3; with Stokes number $\mathrm{St}=\epsilon\tau=5>\mathrm{St}_c=\tfrac14$
the strands cross at the axis (particle trajectory crossing), forming the braided
"plait".  `check.py` anchors the exact closed form on each strand and requires the
zero-slip clock ($u\equiv u_{g0}$), the per-row match, and an axis crossing.  Note
that the paper's Eq. 5.4 oscillatory branch has a sin **sign typo** (it fails
$V_{p0}=0$); the oracle uses the corrected $+\sin$ form, which the IGLOO run —
integrating the ODE directly — confirms to the output floor.  A non-uniform gas
needs `gas-order = 2` (2nd-order rebuild); `gas-order = 1` is a piecewise-constant
staircase.

**Result:** worst residual $\sim 5\cdot10^{-7}$ across six strands.

### swirl-wedge

A **swirling** carrier on an **axisymmetric wedge**: a generated
one-cell-thick annular wedge (`tools/make_wedge_case.py`, $\delta = 1^\circ$,
$r \in [0.19, 0.99]$) carrying the solid-body swirl $W = \Omega y$, $\Omega = 0.2$, into
which three DB parcels are injected with a prescribed azimuthal velocity (co-rotating,
spin-up from rest, over-spun; $\tau = 2$ s, $\mathrm{St} = \tau\Omega = 0.4$).  Each
spirals outward — a parcel feels no pressure gradient, so the centrifugal term $w^2/r$ is
unbalanced — and crosses 8–33 one-degree sectors, so the wedge fold (position **and**
velocity rotated back into the sector) runs on every parcel.  `check.py`
integrates the exact cylindrical ODE $\dot r = v_r$, $\dot\theta = w/r$,
$\dot v_r = -v_r/\tau + w^2/r$, $\dot w = (\Omega r - w)/\tau - v_r w/r$ from the
injection state (RK4; step-halving and a 6-state Cartesian re-formulation agree to
$10^{-12}$) and gates $r$, $w_p$, $v_r$ and the unwrapped azimuth every row, plus
in-sector rows and a fold count equal to the oracle's sector count.  The gate sits at
$\approx 6\times$ the F12.6 print floor ($3\cdot10^{-6}$ on $r$, $w_p$, $v_r$;
$8\cdot10^{-6}$ on $\theta$), which is achievable because the gas is sampled at the
parcel's $(x, r)$ and its velocity rotated to the parcel's azimuth (`sampleGas2D`, exact
for any axisymmetric field).  The gate discriminates: reading the $\theta = 0$ components
unrotated at $(x, y)$ misses it by 19–25× on $r$ and $v_r$ (an outward radial bias
$\Delta t_\mathrm{seg}/2\tau$ on the drift), a fold rotating position only by 10–200×
(the parcel stops spiralling), and $\Omega = 0$ produces no folds.

**Result:** measured residual $5\cdot10^{-7}$.

### swirl-wedge-deposit

The same run with `out-file = ALL` and `mollify = off`: what the swirling parcels
**deposit**.  The momentum source and the eulerian field are meridian-plane fields — a
cell $(x, r)$ carries (axial, radial, azimuthal) components — while a parcel on the wedge
sits at an azimuth $\theta$ inside the sector, so every vector it deposits is rotated by
$-\theta$ about the axis first (`Lib_Equations::toMeridian`: the segment's
$\dot m\,(v_\mathrm{in} - v_\mathrm{out})$ at its mid azimuth, the euler moments
$\int v|v|\,dt$ pointwise in the RHS).  With mollification off the fields split by radius
(P3 alone at $r \in [0.30, 0.35]$, P1+P2 at $[0.50, 0.53]$), and `check.py` integrates the
force on the gas $\dot m \int (v - g)/\tau\,dt$ along the parent's exact trajectory in
$(r, \theta)$ components — $F_r = \dot m\int v_r/\tau\,dt$ outward, $F_\theta =
\dot m\int (w - \Omega r)/\tau\,dt$ — and gates the band sums to 2 %, the energy sum against
the kinetic drop, the azimuthal signs (over-spun P3 pushes the gas forward, P1+P2 hold it
back), every P3 cell's $v_p$, $w_p$ against the path average over its dual window
($10^{-4}$), deposit locality and the band mass $\sum\rho_p V = \dot m T$.  The
reference is **not** $\dot m\,\Delta(v_r, w)$: the difference of the meridian
components carries the frame terms $w^2/r$ and $-v_r w/r$, which are not force on the gas,
and a deposit of exactly that flips the sign of the radial sums (247–294 %); a Cartesian
deposit at the parcel azimuth fails 325 of 382 per-cell checks ($v_p$ missing
$-w\sin\theta$) while the band *sums* cannot see it, since the mixing cancels over a
sector sweep.

**Result:** band sums within $0.22$ %; per-cell velocities at the floor
($9\cdot10^{-7}$, $1.5\cdot10^{-5}$); band mass 1.000127.

### swirl-wedge-spin

The third wedge twin: one **over-spun** parcel ($r_0 = 0.2$, $u_p = 0.05$, $w_p = 2$, ten
times the co-rotating speed) whose azimuth advances at $\sim 10$ rad/s at injection, so it
would sweep $\sim 34$ one-degree sectors inside its first $(x, r)$ cell.  The point-in-cell
test carries the sector band (`isPointInsideCell`'s `sectorOut`), the step refinement pins
the segment to the sector plane, and every fold rotates by exactly one sector, so each
segment's deposit lands in the cell the parcel actually occupies.  `check.py` reads the
run's fold witness `wedge sector folds: N (multi-sector: M)` and requires $M = 0$ and $N$
within 2 of the oracle sweep to the outer wall (79 sectors); every row inside the sector;
$w_p$, $v_r$, $u$ at every row against the Cartesian Stokes oracle in the true field, each
row matched to the oracle's closest approach in $(x, r)$ since $u$ is not constant and cannot serve as the clock
(tolerance $2\cdot10^{-5}$, the print floor through the parcel's $20\ \mathrm{m/s^2}$
acceleration); and the eulerian **mass per geo cell** against the oracle's residence time
per dual cell projected with the solver's own dual-to-geo rule (sub-quadrant volume
weights), 2 % on the 97 cells holding $\ge 1$ % of the peak, plus the tiling total
$\sum\rho_p V = \dot m T$.  The per-cell gate is the discriminating one: a segment
spanning several sectors and deposited at its start point puts the first rows of the
injection column off by $+33$ % / $-37$ % while the tiling total stays unchanged.

**Result:** 79 folds, no multi-sector fold; velocity residual $\le 7\cdot10^{-6}$;
cell mass within $4\cdot10^{-3}$; tiling total 1.000044.

### periodic-y

Translational periodic BC (bcdef 201), exercising the transport
path: the body-force decoupling with $g_y = -8000$ drives each particle across
the $y$-periodic pair 2–3 times.  The anchored $v(x)$ closed form must hold
across every wrap (the transport leaves velocity untouched) and $y(x)$ must
equal the unwrapped closed form **modulo $L_y$** (the transport is an exact
$\pm L_y$ translation).

**Result:** residual $\sim 5\cdot10^{-7}$ m.
