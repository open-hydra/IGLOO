IGLOO

Integration of a General Lagrangian One-way ODE set

Open-source Lagrangian particle solver — each particle's ODE state is integrated through a steady background gas field, from injection to exit of the domain, with drag, heat transfer, evaporation, breakup, and eulerian feedback.

Everything you need for dispersed-phase simulation

A complete Lagrangian particle solver written in modern Fortran

Drag & Heat Transfer

Momentum and thermal coupling with the carrier gas through a library of literature drag laws and Nusselt-number correlations.

Evaporation

Opt-in phase change: vapor-pressure driven mass transfer with coupled diameter and temperature evolution.

Secondary Breakup

Five breakup models — from TAB to Reitz KH-RT — with optional child-particle generation and on-the-fly array growth.

Eulerian Feedback

Particle statistics deposited back onto the gas mesh as eulerian and source fields, smoothed by a volume-weighted binomial mollifier.

Parallel Execution

The hot loop is OpenMP-parallel over particles — each one integrates independently through the frozen gas field.

Flexible I/O

Gas fields read from Tecplot files via ORION or injected in-memory by a parent solver. Trajectory, eulerian, and scatter-cloud output.

Up and running in minutes

IGLOO ships with a single install script that builds the bundled dependencies, compiles the Fortran core, and drops the executable in bin/.

Installation guide → Quick start
terminal 
# Clone and build
$ git clone https://github.com/open-hydra/IGLOO.git
$ cd IGLOO && ./install.sh build --master=None --compilers=gnu --use-openmp

# Run the test suite
$ cd test && ./test.sh run
