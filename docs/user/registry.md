# Input Parameters

Solver-owned `input.ini` sections, auto-generated by `DocGen` from the doc-only registry (`src/lib/config/Register_IGLOO.f90`; runtime reader: `Lib_INI.f90`). Phase and boundary sections (`[GPB-Phase*]`, `[BCB-Block*]`) are ATLAS-generated and described in [Input File](input.md).


## IGLOO-General

| Parameter | Default | Allowed | Required | Description |
|-----------|---------|---------|----------|-------------|
| phase | - |  |  no | ATLAS phase name: reads INPUT/<phase>-{phase.txt,properties.dat,bc.txt}; absent = the unprefixed files |
| gas-file | - |  | yes | Tecplot gas solution file; unused when a parent solver injects the gas field |
| gas-order | 2 | 1, 2 |  no | Gas field reconstruction order |
| out-file | E+S | E, S, E+S, ALL |  no | Output field: E = equivalent eulerian, S = coupling source, E+S or ALL = both (also absent/blank); any other token is refused |
| fsample-traj | 100 |  |  no | Scatter-cloud density: nominal points per injection stream; sets the droplets-per-point quantum dNscat = Ndot*tauRef/(fsample-traj*nStreams). Not a trajectory sampling frequency (trajectory rows follow print-dcell/print-dtime) |
| probe-ids | - |  |  no | DEBUG: integrate only the listed particle IDs, space-separated, a-b intervals allowed (e.g. 1 2 6 496-497); absent or empty = all |
| print-dcell | 1 |  |  no | Trajectory print frequency in cell crossings |
| print-dtime | -1 |  |  no | Trajectory print interval [s]; <0 = cell-based printing |
| mdot-max | 0 |  |  no | Maximum mass flow per trajectory [g/s]; 0 = off (spacing from ds) |
| out-traj | on | on, off |  no | Write per-material trajectories-*.dat |
| out-scatter | on | on, off |  no | Write per-material scatter-*.dat number-density point cloud |
| seed | 42 |  |  no | RNG seed for stochastic injection-diameter sampling |
| mollify | on | on, off |  no | Mollify the eulerian/source feedback fields |
| mollify-passes | 8 |  |  no | Binomial smoothing passes; 0 = off; default 8 when mollify is on |
| body-accel | 0 |  |  no | Uniform body acceleration gx gy gz [m/s^2]; absent or all-zero = off |
