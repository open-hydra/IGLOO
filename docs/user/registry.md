# Input Parameters

Solver-owned `input.ini` sections, auto-generated by `DocGen` from the doc-only registry (`src/lib/config/Register_IGLOO.f90`; runtime reader: `Lib_INI.f90`). Phase and boundary sections (`[GPB-Phase*]`, `[BCB-Block*]`) are ATLAS-generated and described in [Input File](input.md).


## IGLOO-General

| Parameter | Default | Allowed | Required | Description |
|-----------|---------|---------|----------|-------------|
| phase | - |  |  no | ATLAS phase name: reads INPUT/<phase>-{phase.txt,properties.dat,bc.txt}; absent = the unprefixed files |
| gas-file | - |  | yes | Tecplot gas solution file; unused when a parent solver injects the gas field |
| gas-order | 2 | 1, 2 |  no | Gas field reconstruction order |
| out-file | E+S | E, S, E+S, ALL |  no | Output field: E = equivalent eulerian, S = coupling source, E+S or ALL = both (also absent/blank); any other token is refused |
| fsample-traj | 100 |  |  no | Scatter-cloud density: nominal markers per injection stream; sets the quantum dNscat = Ndot*tauRef/(fsample-traj*nStreams), a parcel writing npRef/dNscat markers per second (npRef its number rate at entry; a breakup child keeps the rate of its parent). Not a trajectory sampling frequency (trajectory rows follow print-ds, print-dtime and print-dcell) |
| probe-ids | - |  |  no | DEBUG: integrate only the listed particle IDs, space-separated, a-b intervals allowed (e.g. 1 2 6 496-497); absent or empty = all |
| print-dcell | - |  |  no | Diagnostic trajectory cadence: when set, a row at every print-dcell-th cell crossing, at time-end and at a boundary exit, besides print-dtime's rows; print-ds is then ignored; absent = off |
| print-dtime | -1 |  |  no | Trajectory row interval [s]: a row at a segment end when the time since the parcel's last row reaches it; ignored when print-ds is set; with print-dcell set, a row at the first segment end at or past a target time starting one print-dtime after the parcel's start, moved on by print-dtime at every row written; <=0 = off |
| print-ds | -1 |  |  no | Trajectory row distance [m]: a row at a segment end when the parcel is this far from its last row; ignored when print-dcell is set; <=0 = off |
| time-end | -1 |  |  no | Parcel end time [s]: every parcel still in the domain stops there, with a last trajectory row at that time and its state in snapshot-<mat>.dat; <=0 = off (integrate until the parcel leaves the domain) |
| out-time | off | on, off |  no | Append the parcel time [s] as the last column of every trajectory and exit row |
| mdot-max | 0 |  |  no | Maximum mass flow per trajectory [g/s]; 0 = off (spacing from ds) |
| out-traj | on | on, off |  no | Write per-material trajectories-*.dat |
| out-scatter | on | on, off |  no | Write per-material scatter-*.dat number-density point cloud |
| seed | 42 |  |  no | RNG seed for stochastic injection-diameter sampling |
| mollify | on | on, off |  no | Mollify the eulerian/source feedback fields |
| mollify-passes | 8 |  |  no | Binomial smoothing passes; 0 = off; default 8 when mollify is on |
| body-accel | 0 |  |  no | Uniform body acceleration gx gy gz [m/s^2]; absent or all-zero = off |
| timing | off | on, off |  no | Print [IGLOO-timing] lines after each output write: wall time per phase, parcel count and integration time per thread and per rank, rank imbalance, allocated array sizes |
| plane-x | - |  |  no | Planes normal to x at the listed positions [m], space-separated: planes-<mat>.dat holds one record per crossing, with the stream's state, flow, number rate, ID, parent ID and direction; absent = no file |
